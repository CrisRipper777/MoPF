# Figure 4 RCMI final-clean audit and panel contract

## Audit conclusion

The authoritative Figure 4 source is the final-clean `cosi_mag_final`
benchmark under `outputs/cosi_mag_final_benchmark/`, not the earlier
`outputs/rc_iamoc_final_candidate/` checkpoint set.  Movies and Grocery use
the complete NC final-clean runs; `sports-copurchase` uses the complete
final-clean LP runs.  Each has seeds 42, 43, and 44, `complete.marker`, and
seed-specific `best_run1/2/3.pt` checkpoints.

The source CSVs were regenerated by inference-only intervention from those
frozen checkpoints. No optimizer, backward pass, training epoch, clean
benchmark rerun, or model-structure change was used.

## Formal protocols

- NC: `unified_full_graph_nc_v1`, full formal graph inference.
- Sports-LP: `unified_sampled_lp_v1`; the train-only message graph is passed to
  the current final inference path.
- Sports-LP logits in panel (c) are frozen `LinkPredictor` scorer logits on
  the fixed test edge set, after the checkpoint's frozen projection.
- Cloth-LP is excluded.

## Final panel contract

1. **Panel (a), Attended-Order Heterogeneity.**  For each node and modality,
   compute the formal `r_attn` from the attention matrix for each seed, then
   average the same node across seeds.  Plot the resulting node distributions
   for Movies and Grocery with Text/Visual violins, an embedded Q25–Q75 box,
   and a median line.  The y-axis is fixed to `[0, 1]`; no mean point, SD
   whisker, or dense node scatter is used.
2. **Panel (b), Interaction Intervention.**  Use per-seed frozen `Z MAE`
   relative to Normal for Query-Collapse, Uniform-Attention, and
   Interaction-Off.  Show thin paired seed trajectories and a bold
   dataset-level mean trajectory.  The output audit records whether
   `Query-Collapse < Uniform-Attention < Interaction-Off` holds for every seed.
3. **Panel (c), Relation-Context Dependency.**  For Movies, Grocery, and
   Sports-LP, compute per seed and quantity
   `100 * (Shuffle impact / Off impact - 1)` before summarizing.  Show seed
   points and dataset mean markers for Text Attn., Visual Attn., Z, and Logits,
   with a zero reference line.

Existing attention heatmaps, beta profiles, performance metrics, absolute SD
error-bar prototypes, and the former mean-ratio relation summary are not
entered into the正文 figure.  The figure therefore contains exactly the three
panels required by the RCMI story: adaptivity, functional interaction, and
cross-stage relation dependency.
