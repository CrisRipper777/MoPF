# NC Benchmark Results

## 实验设置

- 数据集：`Movies`、`Toys`、`Grocery`、`ele-fashion`、`Reddit-S`
- 模型：原有 13 个实现模型 + 新增 `mopf`
- Seeds：`42/43/44`
- NC 协议：`unified_full_graph_nc_v1`
- 训练方式：transductive full-graph training
- 指标：Validation Accuracy、Test Accuracy、Test Macro-F1
- 表中数值：`mean ± population std`，单位为 `%`
- 原始结果目录：`outputs/full_benchmark/nc/`

原 benchmark 共完成 `5 × 13 = 65` 个 jobs；本次新增 MoPF 的 5 个
`num_runs=3` jobs。原有结果由各模型目录下的 `seed42_runs3/results.json`
汇总而来，MoPF 结果来自本报告列出的 2026-09-09 输出目录。

每个目录均为 `num_runs=3`，模型 seeds 为 42、43、44；数据划分保持固定：MAGB 数据集使用对应的 `*_nc_seed42_*` split，ele-fashion 使用其官方 `split.pt`。所有运行都使用 `model=mopf`，没有改变 NC 主训练协议。

### 统一配置

日志中的 resolved config 对五个数据集一致（数据路径和数据集元信息除外）：

- `task=nc`，`protocol_version=unified_full_graph_nc_v1`，`training_mode=full_graph`。
- AdamW，`lr=1e-3`，`weight_decay=1e-4`，`epochs=300`，`batch_size=1024`。
- 每 epoch 验证，`patience=30`，`early_stop_min_epoch=30`，`early_stop_min_delta=1e-4`，`grad_clip=1.0`。
- `inference_mode=full`，`inference_batch_size=4096`，无 scheduler。
- MoPF：`hidden_dim=256`，`max_order=num_layers=3`，`filter_rank=4`，`separate_cos`，`edge_weight_min=0.1`，`edge_weight_temperature=2.0`，self-loops 开启；global/modality/node 三层 filter 均开启。ele-fashion 重跑使用 `cuda:1`。
- `aux_loss` 固定为零，因此 `task.loss.aux_weight=1.0` 不会额外改变分类目标。

NC 日志中的 `model params` 是 encoder 加线性 classifier 的总数：768+768 输入的 MAGB 数据集为 1,001,312（Toys 为 1,000,798，因为类别数为 18），512+512 输入的 ele-fashion 为 868,184。

### 训练曲线摘要

所有 epoch 都输出了 train loss 和 validation accuracy。下表给出每个数据集三个 seed 的范围，格式为“首 epoch loss → 停止 epoch loss；首 epoch val Acc → 最佳 val Acc”：

| 数据集 | train loss | val Acc | early stopping |
| --- | --- | --- | --- |
| Movies | 2.7257–3.2271 → 0.3843–0.5650 | 32.93 → 56.87–57.35 | epochs 86 / 101 / 101 |
| Toys | 2.9339–3.2338 → 0.1513–0.1975 | 10.32–20.92 → 80.29–80.43 | epochs 84 / 96 / 93 |
| Grocery | 3.2293–3.2904 → 0.0273–0.0806 | 14.14 → 83.51–83.78 | epochs 160 / 109 / 163 |
| ele-fashion | 2.6546–2.8230 → 0.1679–0.2354 | 43.38–61.98 → 88.10–88.25 | epochs 138 / 169 / 178 |
| Reddit-S | 3.0693–3.3356 → 0.0012–0.0023 | 9.94–30.20 → 96.23–96.45 | epochs 92 / 126 / 162 |

首个 epoch 到第二个 epoch 在若干 seed 上出现小幅 loss 上升（例如 Movies seed42 为 2.7993 → 3.3794），之后均进入持续下降趋势。这种随机初始化后的早期波动没有伴随验证崩溃或非有限值。

### 训练是否正常

结论：从日志可观测信号看，模型训练正常，没有发现数值爆炸、训练中断或协议执行异常。

证据如下：

1. 五个目录的 15 个 run 全部完整结束，均正常进入 best-validation checkpoint 的最终测试和三-seed汇总；没有 traceback、ERROR、CUDA OOM、NaN、Inf、non-finite、overflow 或 failed 日志。
2. 所有 run 都明确记录 `Train full graph: enabled by the unified NC protocol`、`Protocol: unified_full_graph_nc_v1` 和 `Inference mode: full`，说明 NC 训练/评估路径正确。
3. train loss 在所有数据集、所有 seed 上从约 2.6–3.3 降到 0.001–0.56；validation accuracy 从接近初始水平逐步提升并进入平台期，而不是发散或塌缩。
4. early stopping 都发生在最大 300 epoch 之前，且停止位置符合 `patience=30` 的配置；best epoch 均早于停止 epoch，说明 checkpoint 选择逻辑正常。
5. test accuracy 的跨 seed 标准差只有 0.06–0.45 个百分点，验证 accuracy 的标准差只有 0.06–0.22 个百分点，整体复现性很好。

需要保留的观察点是 ele-fashion 的 test Macro-F1：seed42/43 为 77.37/77.89%，seed44 为 70.81%，导致汇总标准差达到 3.22 个百分点；但该 seed 的 validation accuracy（88.25%）、test accuracy（88.25%）和 loss 曲线均正常。因此这更像是类别不均衡或少数类预测敏感导致的宏 F1 波动，而不是优化器、梯度或模型数值故障。相较旧跑次，准确率更稳定且略有提升，但 Macro-F1 跨 seed 波动更大。若 Macro-F1 是主要论文指标，正式实验应保留该 seed，并额外检查 class-wise confusion/support；不应直接删除该结果。

### 当前判断

可以将这组结果作为 MoPF NC 的首轮三-seed benchmark 结果，并继续进行正式 seed42/多 seed 性能实验。训练本身没有需要立即修复的问题；后续优先关注 ele-fashion 的宏 F1 跨 seed 方差，并与 MAP-v1/v2/v3 使用完全相同的 split、协议和汇总方式进行横向比较。
